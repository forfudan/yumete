# Bundled common Chinese word dictionary for yumete's segmenter (Feature #24).
#
# Format: one entry per line, "word<TAB>weight" (or "word weight"); blank lines
# and lines beginning with "#" are ignored. Weights are relative frequencies —
# higher means more common — used by the maximum-probability segmentation path.
#
# **This is the fallback, not the dictionary.** With Yume's data installed the
# editor segments with Yume's own language model (`lang.ywl` / `lang.ygram`,
# 繁簡混合, over a million entries) — that is what `w`/`b`/`e` actually use on a
# machine that has run `scripts/build.sh`, and it reads both scripts. This list
# is what is left when there is no data at all: a compact everyday-prose list so
# the word motions and the segmentation overlay work with no setup. A user may
# also override it with a richer "segmentation.txt" in the data directory.
#
# It was simplified-only until 2026-09-04, so *that* machine — and only that
# machine — stepped through 繁體 one 字 at a time.
