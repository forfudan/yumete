# 宇梦小课堂

这是**你自己的文件**，在这里怎么改都只会影响它。
想重新开始：`:tutor` 再开一份。

退出：`:q`。想保留改动就先 `:w`，它已经有文件名了。

────────────────────────────────────────────────────────────

## 一、两种模式，一个 Esc

现在你在 **NORMAL**：键盘上的字母是命令，不是字。
按 `i` 进入 **INSERT**，这时按键就是打字。按 `Esc` 返回。

  ⇒ 把光标移到下面这一行，按 `i`，随便打几个字，按 `Esc`。

    这一行是给你改的。

改坏了？按 `u`，再按 `u`。**`u` 一步步撤销**，`U` 重做。
先记住这一条，后面的练习都能撤回。

────────────────────────────────────────────────────────────

## 二、走

`h` `j` `k` `l` 是左下上右。方向键也行，但用这四个键手不用离开主键区。

汉字之间没有空格，所以词是算出来的：

  ⇒ 光标放到下面这一行的行首，按三次 `w`，看它停在哪里。

    他抬头看了看那片天，雪还在下，山路已经看不见了。

`w` 下一个词首，`b` 上一个词首，`e` 这个词的末尾。
`3w` 是走三次：**数字在前面表示次数**。

在长行里：`gh` 行首，`gl` 行尾，`gs` 第一个非空白字符。
整个文件：`gg` 开头，`ge` 结尾，`30G`（或 `g30g`）到第 30 行。
`C-d` `C-u` 翻半页，`C-f` `C-b` 翻整页。

────────────────────────────────────────────────────────────

## 三、选区：每次移动都会留下一个

这是它和别的编辑器不一样的地方：**先选中，再决定做什么**。
按 `w` 就选中了一个词，这时按 `d` 删掉的就是它。

  ⇒ 在下面这一行上：按 `w` 选一个词，按 `d` 删掉，按 `u` 还原。

    昨天的雪把院子里那棵老槐树压断了一根枝。

  ⇒ 同一行：按 `x` 选中整行，按 `c` 改写它，`c` 会直接进入输入。

`v` 进入选择模式：移动时选区随之扩大。`;` 把选区收成一个字。

────────────────────────────────────────────────────────────

## 四、操作选区

    `d` 删除      `c` 改写（并进入 INSERT）
    `y` 复制      `p` 粘贴到后面
    `>` 缩进      `<` 减少缩进

`.` 重复上一次输入：包括进入插入模式的那个键和打的字。

  ⇒ 在一个词前面按 `i`，打「很」，`Esc`；换到另一个词前面，按 `.`。

────────────────────────────────────────────────────────────

## 五、找

`/` 搜索，输入后按 Enter；`n` 下一处，`N` 上一处。

  ⇒ 按 `/`，打「雪」，Enter，再按几次 `n`。

选中一段后，**`g/` 找它还在哪里出现**，不用重打一遍。

  ⇒ 选中上面一个「雪」，按 `g/`，再按 `n` 去下一处。

替换：`:s/旧/新/` 替换本行第一处，`:%s/旧/新/g` 替换全文。

## 七、把它当成一本书

  ⇒ 输入 `:vertical`，按 Enter。

现在是**竖排**。`h` `l` 换纵（纵从右往左排），`j` `k` 沿着这一纵走。
`:view-wrap-height 24` 定一纵多少字，`:view-pages-vertical 2` 把一页分成上下两段。
`:view-hanging` 让标点挂到字旁边，像印刷的书。
输入 `:horizontal` 回到横排。

  ⇒ 输入 `:indent full`，按 Enter。段首缩进两格，段间空行隐藏了，
     但文件没有变，变的只是显示。`:indent basic` 只缩进、保留空行，
     `:indent off` 恢复原样。

────────────────────────────────────────────────────────────

## 八、表格

下面是一张表。把光标放进去，输入 `:table-render window`，按 Enter。

| 字 | 拆分   | 说明     |
| -- | ------ | -------- |
| 木 | 木     | 树       |
| 相 | ⿰木目 | 看       |
| 杏 | ⿱木口 | 果       |

表格窗口里 `h` `j` `k` `l` 按格走，`Enter` 进格子按字走，`Esc` 退回；`Tab` 走下一格。
`i` 进格子输入，`c` 改写整格，`空格 t r` 加一行，`空格 t d` 删一行
（`空格 t o` 回到源码）。

  ⇒ 光标放到「相」那一行的拆分格上，走到「木」上按 `空格 t /`：
     查找哪些字的拆分用了「木」。`空格 t ?` 做同样的查找，结果显示在另一个区。
     （`空格 t` 是表格的命令组，`g` 是全文的：`gd` `g/` 在表格里也作用于整个文件。
     `t` 在表格里和在正文里一样，是 vi 的 till。）

  ⇒ `:table-jump 木` 跳到「木」自己那一行，`C-o` 回来。

表头上面那一行数字是**列号**：`空格 t 20,20g` 到第 20 行第 20 列，
`空格 t 1s` 按第 1 列排序（`1a2d8as` 按多列排序，`0s` 按光标所在列），
`空格 t 3/` 只在第 3 列里找（`2-10?` 是第 2–10 列）。
`:table-render off` 退出。

## 九、不弄丢东西

`:w` 保存，`:q` 退出，`:wq` 保存并退出。
有改动没保存时 `:q` 会拦住你。确定不要了：`:q!`。

正在编辑的内容会定时自动备份；万一断电，
下次打开时会问你要不要 `:recover`。

`空格 f` 找文件，`空格 e` 浏览目录，`空格 b` 切换文件，`:sidebar-explorer` 打开侧栏。
