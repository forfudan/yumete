# 大陸通規繁體字形（`:convert … c`）
#
# 左邊是 opencc 交出來的字形，右邊是這個標準要的字形。`:convert` 在 opencc 跑完
# 之後拿它逐字掃一遍——一個字換一個字，不看上下文，所以字數一個不多一個不少。
# 一行 `舊<TAB>新`；右邊給了幾個候選就取第一個。只有一欄的那幾行是另一件事，見檔尾。
# `#` 開頭與空行跳過。
#
# 正文原樣抄自 GujiCC（Apache-2.0，https://github.com/forFudan/GujiCC）的
# generator/china/s2c_characters.txt，連作者的取捨註記一起。**別手改這一段**：要改
# 去上游改，再整段抄回來。
#
# 底下「補」那一節是這裏加的。上游那張表是給它自己的 opencc 配置當覆蓋源用的，
# 有兩行的左邊是**簡體**字頭；而我們是在官方 s2t 之後纔跑，那時候它們已經是繁體
# 形了，原樣的鍵一輩子命中不了。拿 4003 個簡體字頭窮舉比對過，補上這兩行之後與
# GujiCC 自己的 s2c／s2g 只差三個字（托 栗 硷），那三個是 opencc 的 s2t 本身就
# 沒有的條目，任何字形表都夠不着。

# 反不回去的那幾行（`:convert c t` 這一路用得着）
#######
#
# 一行一個字形，只有一欄。意思是：這個字形出現在通規文本裏的時候，**倒推不出來
# 源**，所以往回走那一趟原樣留着它。
#
# 判準不是拍腦袋，是問 opencc 自己：把 STCharacters／STPhrases 兩本字典解出來
# （`opencc_dict -f ocd2 -t text`），看它的繁體側吐不吐得出這個字形。吐得出，就
# 表示上面那一行是**兩個都在用的字形被通規併成了一個**——虱、蝨——倒回去沒有唯一
# 答案；吐不出（説 内 吴 録 這些），就表示它只可能是這張表自己換出來的，倒得回去。
#
# 併掉的那幾個字認了：往回走的時候不猜，讓 opencc 的 t2tw／t2s 按它自己的規矩處理。
