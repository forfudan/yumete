# Third-party notices

The `one-dark`, `zed-one-dark` and `monokai` themes copy colour values from other projects,
all under the MIT license. Their notices are kept here, unchanged.

| File | Project | What is used |
| --- | --- | --- |
| `one-dark-pro.LICENSE` | [One Dark Pro](https://github.com/Binaryify/OneDark-Pro), `themes/OneDark-Pro.json` | the code and Markdown colours (`ONE_DARK_PRO` in `crates/yumete-config/src/lib.rs`) |
| `atom-one-dark.LICENSE` | [Atom One Dark](https://github.com/atom/atom/tree/master/packages/one-dark-syntax), which One Dark Pro is based on | the palette those colours come from |
| `zed-one-dark.LICENSE` | [Zed](https://github.com/zed-industries/zed), `assets/themes/one/one.json` (its One Dark, after Atom's) | the code and Markdown colours of `zed-one-dark` (`ZED_ONE_DARK`) |
| `vscode.LICENSE` | [VS Code](https://github.com/microsoft/vscode), `extensions/theme-monokai/themes/monokai-color-theme.json` | the code and Markdown colours of `monokai` (`MONOKAI`) |
| `colorsublime-themes.LICENSE` | [Colorsublime-Themes](https://github.com/Colorsublime/Colorsublime-Themes), which VS Code's Monokai comes from | the palette, after Wimer Hazenberg's original Monokai |
