# The yumete manual

Yumete is a terminal editor for Chinese writing, with selection-first editing,
vertical layout, and an integrated Yume input method.

Start with [Getting started](manual/02-getting-started.md), or run `:tutor` for a
Chinese lesson you learn by editing. Use the contents to read by subject.

For a specific command, key, or configuration option, see [Using help](help.md).
The [command reference](manual/73-commands.md) and
[configuration reference](manual/79-configuration.md) support lookup while you work.

English is the complete reference. [简体中文](../zh-Hans/index.html) and
[繁體中文](../zh-Hant/index.html) use Traditional Chinese sources, with Simplified Chinese generated automatically; untranslated pages
are explicitly identified and use the English source.
